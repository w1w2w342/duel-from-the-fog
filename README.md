# DUEL FROM THE FOG (Python Edition)

## Описание

DUEL FROM THE FOG (Python Edition v5.2.6) — соревновательный сетевой 3D-шутер от первого лица с тактической механикой стрельбы, разработанный на языке Python с использованием игрового движка Ursina Engine (на базе Panda3D) и графического интерфейса пользователя PyQt6. Проект реализует сессионные сетевые матчи в режимах каждый сам за себя (FFA), командного боя (TDM) и гонки вооружений (Arms Race), а также одиночный оффлайн-режим тренировки на полигоне с ботами и интерактивными мишенями.

Сетевая архитектура проекта построена на базе выделенного и клиентского TCP-сервера с непрерывным вещанием состояния мира с частотой 128 тиков в секунду (TICK_RATE = 128). В игре реализована соревновательная баллистика: детерминированный паттерн отдачи для автомата M4, механика веерной стрельбы от бедра («Fan the Hammer») и случайного критического патрона («Lucky Chamber») для револьвера, динамическое расширение прицела при движении, независимые хитбоксы анатомических зон персонажа, голосование за выбор следующей карты и Rich Presence интеграция с Discord.

## Технический стек

- **Python 3.11 / 3.12 / 3.14**: Основной язык программирования игровой логики, сетевой подсистемы, симуляции игрока и интерфейсов.
- **Ursina Engine (Panda3D 10.x / panda3d-gltf)**: 3D-движок реального времени, отвечающий за рендеринг геометрии мешей (.obj), шейдерное освещение с тенями (`lit_with_shadows_shader`), позиционирование 3D-звуков и контроллер от первого лица (`FirstPersonController`).
- **PyQt6 (Qt 6.x)**: Полноэкранный графический лаунчер предстартовой настройки (выбор карты, создание лобби, подключение по IP, параметры звука, чувствительности мыши, FOV и разрешения экрана).
- **TCP Sockets (`socket`, `threading`, `ujson`)**: Сетевой транспорт на базе неблокирующих сокетов с флагом `TCP_NODELAY` (алгоритм Нейгла отключен), синхронизацией пакетов с разделителем новой строки (`\n`) и оптимизированной быстрой JSON-сериализацией через `ujson`.
- **Discord RPC (`pypresence`)**: Интеграция с клиентом Discord для отображения текущей карты, режима матча, счета и времени в статусе профиля.
- **Pillow (PIL) & screeninfo**: Обработка растровых текстур и опрос параметров монитора для адаптивного масштабирования интерфейса.
- **PyInstaller**: Инструмент сборки проекта в автономные бинарные дистрибутивы Windows (`compile.py`, `setup_and_build.bat`).

## Ключевые особенности / Архитектура

### Сетевая синхронизация и тикрейт (128 Hz)
- **Частота тиков 128 TPS**: Серверный цикл (`server.py`) функционирует с тикрейтом `TICK_RATE = 128` (интервал отправки пакетов ~7.8 мс), обеспечивая киберспортивную отзывчивость сетевого взаимодействия.
- **Потоковый протокол TCP**: Взаимодействие осуществляется по порту 7777 (буфер 4096 байт). Использование `ujson` снижает накладные расходы на сериализацию и парсинг пакетов в 3-5 раз по сравнению со стандартным модулем `json`.
- **Авторизация и античит**: При подключении клиент передает расширенный пакет авторизации, включающий хеш клиента (`anticheat.get_client_hash()`), флаги хоста, ID комнаты и пароль.
- **Интерполяция позиций**: Удаленные игроки (`RemotePlayer`) сглаживают перемещение функцией `lerp(position, target_pos, min(1, time.dt * 15))`, исключая телепортацию при сетевых колебаниях.

### Баллистика, паттерны отдачи и арсенал
- **Анатомические хитбоксы**: Модель персонажа состоит из 5 независимых зон коллизий: голова (`head`, урон x2.5), торс (`body`), ноги (`legs`, урон x0.75) и руки (`arms`).
- **M4 (Паттерн отдачи из 20 выстрелов)**:
  - Автомат обладает детерминированной таблицей смещения траектории `pattern` (20 шагов), имитирующей классический CS-спрей с вертикальным подъемом и последующим горизонтальным уводом вправо и влево.
  - Камера игрока получает вертикальный импульс подброса (`kick = 0.7`).
- **Револьвер**:
  - Высокий базовый урон (40 HP).
  - Спецспособность «Fan the Hammer»: веерная стрельба при зажатии ПКМ (быстрый отстрел оставшегося барабана с повышенным разбросом).
  - Пассивная способность «Lucky Chamber»: один случайный патрон в каждом снаряженном барабане наносит критический тройной урон.
- **Дробовик**:
  - Залп из 6 дробин (`pellets = 6`), каждая наносит по 15 единиц урона на ближней дистанции с повышенным конусом разлета (`spread = 1.5`).
- **Снайперская винтовка AWP**:
  - 100 единиц базового урона (гарантированное устранение при попадании в тело или голову), нулевой базовый разброс при прицеливании (`spread = 0.0`) и оптический зум с переключением кратности.
- **Динамический разброс и прицел**:
  - Зазор перекрестия (`crosshair_gap`) плавно расширяется с 0.01 до 0.04 при перемещении персонажа, снижая точность стрельбы на бегу.
  - Наличие пула трассеров на 30 объектов (`tracer_pool`), исключающего создание и уничтожение сущностей во время перестрелки.

### Игровые режимы и логика раундов
- **FFA (Каждый сам за себя)**: Сражение до 5 фрагов одного из участников с мгновенным возрождением на случайных точках спавна.
- **TDM (Командный бой 2x2 / NxN)**: Сражение команд «Красные» и «Синие» до 8 очков либо по истечении таймера раунда (300 секунд). Выбор команды осуществляется через всплывающее меню `TeamSelectionMenu`.
- **ARMS_RACE (Гонка вооружений)**: Соревновательный режим со сменой вооружения по мере набора фрагов до достижения 20 очков.
- **Голосование за карту (`map_voting.py`)**: По завершении матча запускается интерфейс выбора следующей локации среди 7 доступных карт с серверным подсчетом голосов.

## Требования

- **Операционная система**: Windows 10 / Windows 11 (64-бит).
- **Интерпретатор Python**: Python версии 3.11 или 3.12 (рекомендуется 64-битная версия). Поддерживается работа в Python 3.14.
- **Видеокарта**: Графический адаптер с аппаратной поддержкой OpenGL 3.0+ и актуальными драйверами.
- **Оперативная память**: Не менее 4 ГБ RAM.
- **Сетевое подключение**: Доступность TCP-порта 7777 для входящих соединений при создании локального или виртуального сервера (Radmin VPN, LAN).

## Установка и запуск

1. **Клонирование репозитория**:
   Перейдите в каталог проекта:
   ```bash
   cd "D:\Progarm\Readme\5.2.6"
   ```

2. **Создание и активация виртуального окружения Python**:
   ```powershell
   # Создание виртуального окружения
   python -m venv .venv

   # Активация в PowerShell
   .\.venv\Scripts\Activate.ps1
   ```

3. **Установка зависимостей**:
   Установите необходимые библиотеки из файла `requirements.txt`:
   ```powershell
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

4. **Запуск лаунчера и игры**:
   Запустите главный графический лаунчер:
   ```powershell
   python main.py
   ```
   В окне лаунчера доступны:
   - Ввод никнейма игрока;
   - Настройка графики, звука, чувствительности мыши и FOV;
   - Выбор карты (`Даст2`, `АНГАР`, `МЕТРО`, `АЭС`, `ПЕЙНТБОЛ`, `БИТВА НА AWP`, `СЛУЧАЙНАЯ АРЕНА`);
   - Запуск локального сервера (флаг «Создать сервер») или подключение к удаленному хосту по IP-адресу.

5. **Прямой запуск выделенного сервера (Dedicated Server)**:
   Для запуска сервера без графического интерфейса:
   ```powershell
   python server.py
   ```

6. **Быстрый запуск тренировочного полигона (Offline Training)**:
   Для входа на тестовую карту с мишенями и ботами в обход сетевого лобби:
   ```powershell
   python blender_training_map.py
   ```

7. **Сборка автономного исполняемого файла (.exe)**:
   Сборка проекта через PyInstaller с помощью встроенного скрипта:
   ```powershell
   python compile.py
   ```

## Управление / Использование

### Клавиши перемещения и действий
- **W, A, S, D**: Перемещение персонажа (вперед, влево, назад, вправо).
- **Пробел (Space)**: Прыжок.
- **Левый Shift**: Ускоренный бег (спринт с расходом шкалы выносливости `stamina`).
- **ЛКМ (Левая кнопка мыши)**: Стрельба из активного оружия (одиночные выстрелы, очередь или дробь).
- **ПКМ (Правая кнопка мыши)**: 
  - Включение оптического прицела для AWP (переключение кратности зума);
  - Активация веерной стрельбы «Fan the Hammer» для револьвера.
- **R**: Перезарядка оружия с воспроизведением пошаговых звуковых эффектов.
- **1, 2, 3, 4**: Быстрое переключение оружия:
  - `1`: Штурмовая винтовка M4 (20 патронов в магазине, контроль отдачи);
  - `2`: Помповый дробовик (5 патронов, залп из 6 дробин);
  - `3`: Снайперская винтовка AWP (5 патронов, 100 урона, оптический прицел);
  - `4`: Револьвер (6 патронов, 40 урона, спецрежимы стрельбы).
- **Tab (удержание)**: Просмотр турнирной таблицы счета (`Scoreboard`) со списком игроков, команд, текущим пингом, убийствами и смертями.
- **Escape**: Пауза, освобождение системного курсора мыши и выход в меню.
