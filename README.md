# DUEL FROM THE FOG

**DUEL FROM THE FOG** — динамичный трехмерный сетевой шутер от первого лица (FPS), полностью разработанный на Python. Главная особенность проекта — напряженные дуэльные столкновения в условиях ограниченной видимости (тумана), требующие мгновенной реакции, точного позиционирования и тактического контроля пространства.

---

## 1. Концепция и игровые режимы

* **Жанр:** 3D Сетевой тактический шутер от первого лица (FPS).
* **Сеттинг:** Локальные и открытые дуэльные полигоны с плотным атмосферным туманом, превращающим каждый раунд в игру на слух и реакцию.
* **Игровые режимы:**
  * **FFA (Free For All):** Классический бой на выживание без деления на стороны. Побеждает игрок, первым совершивший 5 фрагов.
  * **TDM (Team Deathmatch):** Командное противостояние Красной и Синей команд. Игра ведется до 8 командных очков либо до истечения лимита времени (5 минут).
  * **ARMS RACE:** Динамичная гонка вооружений с моментальным перерождением. Каждое устранение противника автоматически переключает оружие на следующее. Лимит победы — 20 фрагов.

---

## 2. Технологический стек

Архитектура проекта построена на Python-экосистеме с акцентом на высокую скорость сетевого отклика и независимый клиентский лаунчер:

| Компонент | Технология / Библиотека | Назначение |
| :--- | :--- | :--- |
| **Язык программирования** | Python 3 | Базовая архитектура, логика игрока, просчет физики и серверный цикл. |
| **3D-движок** | Ursina Engine (на базе Panda3D) | Отрисовка геометрии, коллизии, динамический свет, тени, шейдеры и FPS-камера. |
| **Лаунчер и GUI** | PyQt6 | Пре-клиент с управлением настройками графики/звука, лобби, сменой ника, вводом IP/пароля и статистикой. |
| **Сетевой стек** | Python Sockets + ujson + threading | Выделенный сервер с тикрейтом 128 Hz (Tick Rate) для плавной регистрации попаданий и минимизации лагов. |
| **Интеграция** | Discord RPC (pypresence) | Отображение активного статуса игры: текущей карты, режима и фрагов в профиле пользователя. |
| **3D-моделирование** | Wavefront (.obj + .mtl), panda3d-gltf | Загрузка уровней, ассетов вооружения, мешей персонажей и зон хитбоксов. |
| **Аудиодвижок** | Встроенный модуль звука Ursina | Пространственное позиционирование звуков шагов, доставания оружия, затворов и зума. |
| **Система профиля** | JSON / Custom Player_stat module | Локальный и сессионный учет K/D, общего игрового времени, числа матчей и побед. |

## 3. Арсенал и баллистика

В игре реализована строгая модель хитбоксов (Head, Body, Legs, Arms) с повышенным множителем урона за попадание в голову:

* **M4A1 (Автоматическая винтовка):** Основное автоматическое оружие. Имеет фиксированный процедурный паттерн отдачи (Recoil Pattern по осям X/Y при ведении непрерывного огня).
* **Sawed-Off (Обрез):** Оружие ближнего боя с широким конусом разлета картечи (6 независимых пеллет за выстрел).
* **AWP (Крупнокалиберная снайперская винтовка):** Оружие с уроном 100 HP (летальный выстрел при попадании в верхнюю часть корпуса). Оснащена оптическим прицелом (Scope UI) со звуком переключения и изменением угла обзора (FOV).
* **Revolver (Тяжелый револьвер):**
  * *Механика Fan the Hammer:* Альтернативный режим скоростной стрельбы «веером» по нажатию ПКМ.
  * *Механика Lucky Chamber:* Случайный выбор одного патрона в барабане с повышенным критическим уроном.

## 4. Карты и ротация

Проект включает набор 3D-арен, оптимизированных под разные тактические дистанции:

* `dust2.obj` — классическая соревновательная арена с длинными коридорами и плентами.
* `metro.obj` — закрытая станция метрополитена с колоннами и слепыми зонами.
* `awp_fite.obj` — симметричная открытая арена для снайперских перестрелок.
* `nuclear.obj` — индустриальный комплекс атомной станции с техническими переходами.
* `angar.obj` — компактный ангар для контактных схваток.
* `paintball.obj` — симметричное тренировочное поле с фанерными укрытиями.
* `random_arena.obj` / `my_map.obj` — экспериментальные локации для пользовательских тестов.

**Map Voting System:** После завершения матча запускается экран голосования за следующую карту, автоматически переводящий лобби на выбранный уровень.

## 5. Графика, интерфейс и клиентские опции

* **Настройки рендеринга:** Переключение Fullscreen/Windowed, изменение разрешения экрана, лок частоты кадров (Max FPS), VSync, кастомизация цвета перекрестия прицела и чувствительности сенсора мыши.
* **HUD и информация о матче:** Встроенный Scoreboard по клавише TAB со списком игроков, пингом и счетом, а также динамический Killfeed событий ликвидации в углу экрана.
